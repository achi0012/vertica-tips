Vertica 資料庫技術筆記與最佳實踐。

## 關於

這個專案使用 GitHub Pages + Jekyll 建置，發表 Vertica 資料庫相關的技術文章，
涵蓋資料載入、效能調優、監控診斷、SQL 技巧等主題。

## 本機開發

```bash
# 安裝相依套件
gem install bundler jekyll
bundle install

# 啟動本機預覽
bundle exec jekyll serve --livereload
```
