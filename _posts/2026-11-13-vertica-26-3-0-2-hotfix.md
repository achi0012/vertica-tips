以下依 Vertica 官方 release notes 逐條整理，模組名稱保留英文原文，說明以中文改寫、內容對應原文，不另加評論。

## 一、26.3.0-2（Updated 10/9/2026）

| Issue Key | Application Module | 說明 |
|---|---|---|
| `118790`、`118756` | UI - Management Console | 本次更新修補 Management Console 所使用的 Bouncy Castle 函式庫中被識別出的重大安全漏洞（CVE-2026-71885） |
| `118339` | Security | 本次更新修補 Vertica container images 隨附之 Go binary 中的多個安全漏洞 |
| `118192` | UI - Management Console | 將 Vertica 使用的 Log4j 升級至 2.25.5 版，以修補較早版本中被識別出的安全漏洞 |

## 二、26.3.0-1（Updated 9/24/2026）

| Issue Key | Application Module | 說明 |
|---|---|---|
| `118375` | UI - Management Console | 本次更新修補 Management Console 所使用的 Apache FreeMarker 中被識別出的重大安全漏洞（CVE-2026-84939）；該函式庫已升級至 2.3.35 版以完成修補 |
| `118374` | UI - Management Console | 本次更新修補 Management Console 所使用的 Spring Security 中被識別出的重大安全漏洞（CVE-2026-59270）；該函式庫已升級至 7.1.1 版以完成修補 |

## 三、26.3.0-0（Updated 9/23/2026）

| Issue Key | Application Module | 說明 |
|---|---|---|
| `114511` | UI - Management Console | 修正 Management Console 的 load monitor 頁面中，文件連結的顯示問題 |
| `114340` | UI - Management Console | 確認 Management Console 不受 CVE-2024-22233、CVE-2024-22234、CVE-2024-22236 與 CVE-2024-22243 影響 |
| `100267` | UI - Management Console | 修正 Management Console 中，於 Query Execution 頁面執行之查詢，在 Query Plan 頁面未顯示 profile 資訊的問題 |
| `25453` | UI - Management Console | 修補 Management Console 中被識別出的安全漏洞（CVE-2022-35980）：使用者輸入欄位未正確過濾，可能遭注入攻擊 |
| `24877` | Third Party Tools Integration | 修補 Management Console 所使用的 Node.js 與 node-tar 模組中的多個安全漏洞，包含 CVE-2023-32002、CVE-2023-32003、CVE-2023-32004、CVE-2023-32005、CVE-2023-32006、CVE-2023-32558、CVE-2023-32559 與 CVE-2024-28863 |
| `11508` | UI - Management Console | 修補被識別出的重大安全漏洞（CVE-2025-12453），性質為反射型跨站腳本（Reflected Cross-Site Scripting），主要影響 10.0.1 版。在此修正之前，已通過驗證的攻擊者可利用特定 Web UI 端點中未受管控的輸入參數，注入並執行任意 JavaScript 程式碼。本次更新包含相關安全強化，並確保使用者輸入經過適當的清理與中和處理，以避免惡意腳本被執行 |
| `4492` | Documentation | 修正 `CREATE FLEX TABLE` 的文件內容：說明以查詢建立 flex table（`CREATE FLEX TABLE … AS SELECT`）時，不支援 `ENCODED BY` 子句 |
| `2923` | HTTP | 修正 MCP Server 的 DSN builder 未對密碼進行 percent-encode 的問題；先前若密碼含有 `@`、`:` 或 `#` 等 URL 保留字元，會導致連線失敗 |
| `2898` | Security | 強化 Management Console 的 Content Security Policy（CSP）標頭：移除 `unsafe-inline` 與 `unsafe-eval` 指示詞，以降低跨站腳本攻擊的風險 |
| `2189` | UI - Management Console | 修正透過 reverse proxy 登入 Management Console 時，出現 `Connection timed out` 錯誤的問題 |
| `1402` | Security | 修補 Vertica Server 與 Vertica Operator 隨附之第三方元件的多個安全漏洞，涵蓋 Python 3.13、Go 標準庫，以及 Node Management Agent、Prometheus 整合與 MCP Server 所使用的相關 Go 模組 |
