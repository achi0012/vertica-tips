## 25.4.0-14（Updated 11/17/2026）

| Issue Key | Application Module | 說明 |
|---|---|---|
| `119767` | Eon | 修復節點停止或遺失時，若長時間執行的會話仍將該節點列於訂閱中，向已停機節點傳送 catalog 差異會在 dc_errors 產生不必要的 TransferService 錯誤訊息的問題 |
| `119448` | Execution Engine | 修復含 lateral UNNEST 的檢視執行 CREATE VIEW 會以 ROLLBACK 2241（invalid relation）失敗的問題，即使等效查詢在檢視之外可正常執行 |
| `119376` | Sessions | 修復以 dbadmin 或其他超級使用者身分查詢 v_catalog.tables 或 v_catalog.views 的會話可能不斷累積且無法終止的問題 |
| `118718` | Client Drivers - JDBC | 新增 JDBC driver 參數 md5AuthEnabled，回應對 Vertica JDBC driver 的靜態程式碼安全分析結果 |
| `118167` | Execution Engine | 修復特定查詢操作因重複 clock_gettime 函式呼叫造成間歇性 CPU 使用率偏高的問題 |
| `2844` | Complex Types | 對回傳複雜陣列型別（例如 ARRAY[ROW(varchar)] 或 ARRAY[ARRAY[varchar]]）的 CASE 運算式套用 unnest() 建立檢視，不再失敗 |
