Each entry below corresponds to the Issue Key, Application Module, and Description in the official Vertica release notes. Module names are kept in their original English form; the descriptions are translated and edited from the original without commentary.

## 25.4.0-14 (Updated 11/17/2026)

| Issue Key | Application Module | Description |
|---|---|---|
| `119767` | Eon | Fixed an issue where stopping or losing a node while a long-running session still had it in its subscriptions generated unnecessary TransferService error messages in dc_errors when sending catalog diffs to the down node |
| `119448` | Execution Engine | Fixed an issue where CREATE VIEW could fail with ROLLBACK 2241 (invalid relation) for views containing a lateral UNNEST, even though the equivalent query executed successfully outside a view |
| `119376` | Sessions | Fixed an issue where sessions querying v_catalog.tables or v_catalog.views as dbadmin or another superuser could accumulate and become unkillable |
| `118718` | Client Drivers - JDBC | Added a new JDBC driver parameter, md5AuthEnabled, in response to findings from a static code security analysis of the Vertica JDBC driver |
| `118167` | Execution Engine | Fixed an issue where certain query operations could cause intermittent high CPU usage from repeated clock_gettime function calls |
| `2844` | Complex Types | Creating a view with unnest() applied to a CASE expression that returns a complex array type (e.g., ARRAY[ROW(varchar)] or ARRAY[ARRAY[varchar]]) does not fail anymore |
