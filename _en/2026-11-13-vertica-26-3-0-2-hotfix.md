Each entry below corresponds to the Issue Key, Application Module, and Description in the official Vertica release notes. Module names are kept in their original English form; the descriptions are translated and edited from the original without commentary.

## 1. 26.3.0-2 (Updated 10/9/2026)

| Issue Key | Application Module | Description |
|---|---|---|
| `118790`, `118756` | UI - Management Console | This update addresses the critical security vulnerability (CVE-2026-71885) identified in the Bouncy Castle libraries used by the Management Console |
| `118339` | Security | This update addresses multiple security vulnerabilities in the Go binaries shipped with Vertica container images |
| `118192` | UI - Management Console | The Log4j used by Vertica is updated to version 2.25.5 to address security vulnerabilities identified in earlier versions |

## 2. 26.3.0-1 (Updated 9/24/2026)

| Issue Key | Application Module | Description |
|---|---|---|
| `118375` | UI - Management Console | This update addresses the critical security vulnerability (CVE-2026-84939) identified in the Apache FreeMarker library used by the Management Console; the library has been upgraded to version 2.3.35 to remediate it |
| `118374` | UI - Management Console | This update addresses the critical security vulnerability (CVE-2026-59270) identified in the Spring Security library used by the Management Console; the library has been upgraded to version 7.1.1 to remediate it |

## 3. 26.3.0-0 (Updated 9/23/2026)

| Issue Key | Application Module | Description |
|---|---|---|
| `114511` | UI - Management Console | Fixed an issue with the display of a documentation link on the load monitor page in the Management Console |
| `114340` | UI - Management Console | Confirmed that the Management Console is not impacted by CVE-2024-22233, CVE-2024-22234, CVE-2024-22236, or CVE-2024-22243 |
| `100267` | UI - Management Console | Fixed an issue where the Query Plan screen in the Management Console showed no profile information for queries run from the Query Execution screen |
| `25453` | UI - Management Console | This update addresses the security vulnerability (CVE-2022-35980) identified in the Management Console, where user input fields were not properly sanitized against injection attacks |
| `24877` | Third Party Tools Integration | This update addresses multiple security vulnerabilities in the Node.js and node-tar modules used by the Management Console, including CVE-2023-32002, CVE-2023-32003, CVE-2023-32004, CVE-2023-32005, CVE-2023-32006, CVE-2023-32558, CVE-2023-32559, and CVE-2024-28863 |
| `11508` | UI - Management Console | This update addresses the critical security vulnerability (CVE-2025-12453), a Reflected Cross-Site Scripting flaw primarily affecting version 10.0.1. Prior to this fix, an authenticated attacker could exploit unmanaged input parameters in certain Web UI endpoints to inject and execute arbitrary JavaScript code. This update includes security enhancements and measures that ensure user-supplied input is properly sanitized and neutralized to prevent the execution of malicious scripts |
| `4492` | Documentation | Corrected the `CREATE FLEX TABLE` documentation to indicate that the `ENCODED BY` clause is not supported when creating a flex table from a query (`CREATE FLEX TABLE … AS SELECT`) |
| `2923` | HTTP | Fixed an issue where the MCP Server DSN builder did not percent-encode passwords, causing connection failures for passwords containing URL-reserved characters such as `@`, `:`, or `#` |
| `2898` | Security | Strengthened the Management Console Content Security Policy (CSP) header by removing the `unsafe-inline` and `unsafe-eval` directives to reduce exposure to cross-site scripting attacks |
| `2189` | UI - Management Console | Fixed an issue that caused `Connection timed out` errors when logging in to the Management Console via a reverse proxy |
| `1402` | Security | This update addresses multiple security vulnerabilities in third-party components bundled with Vertica Server and the Vertica Operator, including Python 3.13, the Go standard library, and the associated Go modules used by the Node Management Agent, Prometheus integration, and MCP Server |
